# Granny flat, Blakehurst: 3D tour and photos

A static site published with GitHub Pages: https://flythrough.homes/blakehurst/

It has three parts:
- **Getting there**: a fly-over from the street to the front door.
- **The flat in 3D**: an explorable model.
- **Photos**: each shows where it was taken on the floor plan.

This repo holds only the **built output**. The source lives in a separate private project (`grannyflat`). To update the site, run `npm run deploy` there, then commit and push here.

3D models: Kenney Furniture Kit and Quaternius Stylized Nature MegaKit (both CC0).
